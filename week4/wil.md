이번 주차에서는 쇼핑몰 프로젝트를 기반으로 ERD 설계부터 JPA를 이용한 엔티티 구현, 그리고 Postman을 활용한 API 테스트까지 진행하였다. 우선 ERD를 통해 Member, Product, Order 세 개의 주요 엔티티와 그 관계를 설계하였다. Member는 회원의 기본 정보를 저장하고, Product는 상품의 이름, 가격, 재고, 설명, 판매 상태 등을 관리하며, Order는 주문한 회원과 상품의 정보를 연결하고 결제 금액, 주문일자, 상태 등을 기록한다. 데이터베이스 관계는 한 명의 회원이 여러 개의 주문을 가질 수 있는 1:N 관계, 한 주문이 하나의 상품을 포함하는 N:1 관계로 설정하였다. 이를 바탕으로 각 엔티티 클래스에 @Entity, @Table, @Id, @GeneratedValue 등의 JPA 어노테이션을 적용하고, @ManyToOne과 @JoinColumn을 통해 외래키를 매핑하였다. 엔티티 구현 후에는 Member를 제외한 도메인 중 Product를 선택하여 CRUD API를 Postman으로 테스트했다. POST /products 요청을 통해 상품 등록을 시도했으며, 요청 본문에는 상품명, 가격, 재고, 설명, 상태 값을 JSON 형태로 담았다. 요청 결과, 응답 코드 200 OK와 함께 생성된 상품의 ID가 반환되어 상품 등록이 정상적으로 작동함을 확인했다. 이후 실패 케이스로 존재하지 않는 상품 ID를 GET /products/9999로 조회했을 때 500 Internal Server Error와 함께 “상품을 찾을 수 없습니다.”라는 예외 메시지가 출력되었다. 이를 통해 예외 처리 로직이 정상적으로 동작함을 검증하였다. 마지막으로 H2 콘솔에서 members, products, orders 테이블이 모두 정상적으로 생성된 것을 확인하고, Postman 테스트 결과를 각각 캡처하여 과제 제출용 이미지로 정리하였다. 이번 과제를 통해 ERD 설계와 엔티티 매핑, 그리고 API 기능 검증 과정을 단계별로 실습하며 백엔드 개발의 기본 흐름을 명확히 이해할 수 있었다.
